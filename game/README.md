# Demo Game

Wanna take a look at what NG-PCE can do ?  
Check out this demo game and play it to get a peek at what you'll be able to create with NG-PCE.  

## How do I get the demo ?

If you already have PCE installed, you can simply run `pce demo` to start the demo game. If you don't, you can get the one-click game bundle in the releases section. (So you'll also discover how easy it is to package a game using the incredible `bundle` tool ;-)

## Want to tinker with the demo ?

Sometimes, it is just easier to start from an existing project, or use it as a reference. Instead of cloning the repo manually, you can simply use the `pce init demo` command and your directory will be initialized with the demo game.
